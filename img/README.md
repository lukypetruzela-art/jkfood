# Fotky pro web

## Galerie v úvodu (nahoře na stránce)

Nahrajte fotky do této složky přesně s těmito názvy. Web si je načte sám.

| Soubor | Co na fotce |
|---|---|
| `hero-1.jpg` | Výroba ve Větřkovicích |
| `hero-2.jpg` | Koření a kořenicí směsi |
| `hero-3.jpg` | Sušená zelenina a houby |
| `hero-4.jpg` | Hotová jídla z našich surovin |

- **Formát:** JPG, ideálně čtvercový výřez nebo fotka na šířku (web ji ořízne do tvaru bubliny z loga, střed fotky zůstane vidět).
- **Velikost:** cca 1600 × 1600 px, do 400 kB na fotku.
- Dokud fotka chybí, zobrazí se místo ní šedý zástupný rámeček s názvem souboru.
- Popisky pod fotkami se upravují v `index.html` (atribut `data-cap`).
